# Security policy

This repository contains a research workflow, not a production safety service.

Please report a suspected security issue privately through GitHub's security
advisory feature. Do not open a public issue containing credentials, private
datasets, exported predictions, or sensitive infrastructure details.

The project accepts no operational responsibility for hazard monitoring,
emergency response, plant design, or regulatory compliance. Any real-world use
requires independent domain validation, calibrated instrumentation, controlled
deployment, and approval by qualified process-safety professionals.
